# Seed problems

Classical seed problems and their intuitive proofs are curated in a separate
repository. This directory is a drop point for that corpus (one YAML/JSON file
per seed). Each `ProblemFamily.classical_instance()` currently embeds its own
seed (mutilated chessboard; 13/15/17 chameleons) so the pipeline runs without
the corpus.

Classical seeds are transfer level d0 and are *retrieval controls*, never
evidence of idea discovery.
